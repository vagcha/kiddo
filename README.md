# Kiddo 🦉

Εκπαιδευτική εφαρμογή Android για παιδιά 5–10 ετών, με οδηγό τη Σοφούλα την κουκουβάγια.

## Δραστηριότητες
| | |
|---|---|
| 🎨 **Ζωγραφική** | Πινέλα σε 3 πάχη, 11 χρώματα, γόμα, αναίρεση και αυτοκόλλητα ζωάκια |
| 🎵 **Μουσική** | Ξυλόφωνο 8 νοτών (Ντο–Ντο). Το «Άκου» παίζει το τραγούδι και το «Μάθε το» δείχνει ποιο πλήκτρο να πατήσει το παιδί |
| ❓ **Κουίζ** | Μαθηματικά, Ζώα, Χρώματα και Γράμματα, με ερωτήσεις που διαβάζονται φωναχτά στα ελληνικά |
| 🧩 **Παζλ** | 3 εικόνες (φάρμα, βυθός, διάστημα), σε 3×3 ή 4×4 ανάλογα με την ηλικία |
| 🃏 **Μνήμη** | Ζευγάρια με ζωάκια: 4 ζευγάρια για 5–7 ετών, 6 για 8–10 |
| 🔢 **Μετράμε** | Το παιδί πατάει κάθε ζωάκι και ακούει τον αριθμό. Για 8–10 ετών υπάρχει και πρόσθεση δύο ομάδων |
| 🦉 **Σοφούλα 3D** | 3D μοντέλο που γυρίζει με το δάχτυλο |
| 🎬 **Βίντεο** | Animation εισαγωγής |

Η εφαρμογή έχει δύο επίπεδα δυσκολίας (5–7 και 8–10 ετών) και αστεράκια επιβράβευσης. Η μουσική υπόκρουση κλείνει από την αρχική οθόνη.

## Γραφικά & media
Όλα τα γραφικά φτιάχτηκαν με το **Artlist**:
- Εικόνες: μασκότ, εικονίδια, ζωάκια, σκηνές για τα παζλ, φόντο (GPT Image 2.6)
- Video εισαγωγής (Kling 3.0)
- Μουσική υπόκρουση (Lyria 3)
- 3D μοντέλο της Σοφούλας (Hyper3D Rodin)

## Πώς κατεβάζω το APK
Σε κάθε push στο `main`, το GitHub Actions φτιάχνει μόνο του το APK.
1. Πήγαινε στη σελίδα **Releases** του repo και κατέβασε το `Kiddo.apk` από την πιο πρόσφατη έκδοση.
2. Στο κινητό Android άνοιξε το αρχείο. Αν σου ζητηθεί, επίτρεψε την «Εγκατάσταση από άγνωστες πηγές».

## Τεχνικά
Kotlin, Jetpack Compose, minSdk 24 (Android 7.0+). Δεν χρειάζεται σύνδεση στο internet και δεν ζητάει καμία άδεια.
Για τοπικό build: `./gradlew assembleRelease`
